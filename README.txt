KALAI & AGILA — WEDDING INVITATION

Mobile-first rebuild based on the requested flow.

OPENING FLOW
1. Exact supplied front invitation image is shown first.
2. Guest taps the front invitation / Tap to Open.
3. Maroon wedding curtains open sideways from the center.
4. The exact supplied inside invitation image is revealed.
5. Countdown follows.
6. A separate small invitation glimpse/opening interaction appears AFTER the countdown.
7. Wedding details, reception reminder, memories, venue/map, and private blessing form follow.
8. Exact supplied final invitation image is the last section.

NOTES
- Curtain opening is separate from the post-countdown glimpse and should not be confused with it.
- The supplied memory image is included as memory #15.
- Reception has a Google Calendar reminder link.
- Wishes are currently front-end only; backend/private admin storage can be added later.
- Designed mobile-first for guests viewing on phones.
