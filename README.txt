KALAI & AGILA — WEDDING INVITATION

1. Open index.html locally to test.
2. Upload all files/folders to the root of the GitHub Pages repository.
3. GitHub Pages URL: https://publicshare-art.github.io/kalai-agila-wedding/
4. Guest wishes are stored in Supabase table public."Guest_wishes".
5. Private admin page: https://publicshare-art.github.io/kalai-agila-wedding/admin.html
6. Sign in to admin.html using the Supabase admin user created for this project.

IMPORTANT SECURITY:
- The website uses the Supabase publishable key in browser code. This is intended for public browser use when Row Level Security is configured.
- Do NOT put a database password or service-role/secret key in this project.
- RLS should allow public INSERT only; SELECT/UPDATE/DELETE are restricted to the authenticated admin email policy you created in Supabase.
